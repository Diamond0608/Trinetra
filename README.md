## What is Trinetra?

Trinetra is a wearable device that has an extendable blade which is electrified, like something from a spy movie. It uses 15*18650 batteries giving 60V. The battery holders would have to be place in a jacket inside pocket.

## Printing:
Printables link: https://www.printables.com/model/1821087-trinetra
Print the following pieces only:
1. Top Plate
2. Enclosing Box
3. Button
4. Latching mechanism
5. Seperating plate


## Assembly:
1. Attach springs to the latching mechanism as per the CAD design and attach a blade.
2. Wire the postive of the battery holder to the next battery holders negative and so on, connecting them in series until you have 1 +ve and 1 -ve left
3. To the -ve attach a power switch.
4. Then wire the positive and negative to a capacitor making sure to wrap an unexposed part of the live wire around the extended rod near the blade such that it touches the blade.
5. You can add an LED into the circuit if you want to know when its active but make sure to use a suitable resistor.
6. Use glue to stick any pieces that together if needed.
